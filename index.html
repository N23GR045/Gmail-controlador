Conecta tu Gmail

Solo se leen cabeceras (remitente, servidores, autenticación), nunca el contenido. La sesión dura 1 hora y no se guarda ninguna contraseña.

¿Problemas al conectar?

Error 400: origin_mismatch

En Google Cloud → Clientes → tu cliente → Orígenes de JavaScript autorizados pon exactamente , guarda y espera 5 minutos.

Error 403: access_denied

Google Auth Platform → Público → Usuarios de prueba → añade el Gmail con el que entras. Comprueba que estás en el mismo proyecto donde creaste el ID.

“Google no ha verificado esta app”

Es normal: la app es tuya. Toca Configuración avanzada → Ir a… (no seguro) y marca las dos casillas.

Permiso para archivar

La primera vez que pulses Archivar, Google pedirá un permiso extra para organizar tus correos. En Google Cloud → Acceso a datos añade también gmail.modify. La app solo lo usa para sacar correos de la bandeja de entrada.

No se abre la ventana de Google

Chrome bloqueó la ventana emergente. Permite ventanas emergentes para este sitio y vuelve a tocar Conectar.

👀 Modo demostración: datos inventados. Bloquear y archivar no afecta a ningún Gmail.
